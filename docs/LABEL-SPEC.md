# Label Spec 70x20mm

- Physical size: 70mm x 20mm
- Front: White background, red border 2.5mm, left text: YEAR GAME / NAME / SET, right: #number / GRADE / R / certNumber, bottom center: real DCR logo small, bottom left: barcode
- Back: Dark blue background for label ONLY (not web theme), left grey DCR watermark, center grey shield DCR logo, right QR, bottom white strip: barcode + certNumber
- Sheet: A4 portrait 210x297mm, 5 columns x 8 rows = 40 labels, duplex: front on odd pages, back on even, flip on short edge, margin 2mm, crop marks.
- Print: Use @media print in print-label.css, hide app UI when printing.
