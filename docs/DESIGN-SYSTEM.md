# Design System - RED + WHITE ONLY

## Colors (only these)
- --dcr-red: #C8102E
- --dcr-red-dark: #9B0B22
- --dcr-red-light: #FFE8EB
- --dcr-white: #FFFFFF
- --dcr-black: #111111
- --dcr-gray: #6B7280
- --dcr-border: #E5E7EB

No dark blue background. No green/yellow/blue buttons.

## Logo
- Use only real DCR logo file: public/assets/logo/dcr-logo.png
- Never invent a new logo. Never use full 70x20 label on Home page.
- Logo on header left, small. Logo on label only in Label page.

## Layout
- Desktop: White header, logo left, menu center, Account right. Content max 1200px centered.
- Mobile: White header, red rounded hero, vertical list, bottom nav 4 items fixed.

## Card display on Home
Show only: image, name, set, grade badge (red), cert number. No price, no barcode large, no QR large.
