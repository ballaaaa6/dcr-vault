# Incoming files

Use this folder only as a temporary landing area for files that have not been classified yet.

1. Inspect the file and its contents before using or extracting it.
2. Move web source into `src/`, public web assets into `public/`, documentation into `docs/`, and label-toolkit material into `dcr-tag-70x20/`.
3. Keep a source bundle in `archive/source-packages/` only when it is useful to retain.
4. Remove the processed file from this folder after it has a permanent home.

Do not add files directly to the workspace root unless they are app entry/config files or the root `README.md`, `AGENTS.md`, and `.gitignore`.
