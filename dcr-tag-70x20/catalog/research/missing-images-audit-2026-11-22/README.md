## อ่านผลให้ถูกต้อง

- ตรวจ URL ภาพ 1,087 URL ที่ไม่ซ้ำด้วย HTTP HEAD; สถานะ 200 และ Content-Type เป็น image เป็นหลักฐานว่า endpoint ตอบกลับ ไม่ใช่การดาวน์โหลดและตรวจเนื้อหาทุกภาพ ไม่รับประกันสิทธิ์ใช้ ตราประทับ ภาษาบนภาพ หรือรุ่นพิมพ์
- `ภาพตอบ HTTP 200` ในรายงานเป็นภาพผู้สมัคร ไม่ใช่ยืนยันว่าตรงกับการ์ดในฐานทุกใบ ต้องตรวจหลักฐานในคอลัมน์สุดท้ายก่อนนำเข้า
- ญี่ปุ่น 251 รายการอาศัยชื่อหรือชนิดโปเกมอนในชุดเดียวกัน โดยไม่มีนักวาดช่วยยืนยัน; 12 รายการมีผู้สมัครมากกว่าหนึ่งภาพ ต้องตรวจด้วยคน
- ภาษาญี่ปุ่น `same mapped set and printed number; identity requires review` อาศัยการเทียบชื่อชุดและเลขกับ CardCorpus เพราะชื่อบางใบในฐานเดิมแปลผิด ต้องตรวจ identity และ variant เพิ่ม
- ภาษาอังกฤษ B2a มี 19 รายการที่ชุดและเลขตรงกับ Limitless TCG Pocket แต่ชื่อในฐานต่างจากชื่อแหล่ง ส่วนใหญ่ขาดคำว่า `ex`; ต้องตรวจและแก้ข้อมูลก่อนเลือกใช้ภาพ
- Classic Collection ของอังกฤษใช้เลขลำดับภายในต่างจากเลขพิมพ์บนการ์ด แหล่งภาพจึงเทียบด้วยชื่อชุดย่อย ชื่อการ์ด และต้องตรวจภาพ/ตราครบรอบ ภาพตัวอย่าง 30th-c-001 จาก CardCorpus ตรวจด้วยตาแล้วมีตรา 30th; ภาพบนหน้ารวมของ TCG Journal ที่แสดง Charizard ตัวอย่างกลับมีตรา 25th จึงไม่ควรถือภาพจากหน้านั้นว่าตรงรุ่นโดยอัตโนมัติ
- ไม่พบ URL ผู้สมัครของญี่ปุ่น 286 ใบและอังกฤษ 14 ใบในแหล่งที่เทียบรอบนี้ ไม่ได้หมายความว่าภาพเหล่านั้นไม่มีอยู่ที่อื่น
- ไทย S5a-012 โดคุคุราเกะ: [หน้าทางการ](https://asia.pokemon-card.com/th/card-search/detail/1190/) ตรงชื่อและเลข 012/070 แต่ไฟล์ภาพทางการส่ง HTTP 200 พร้อม body ว่างเมื่อทดลอง GET ล่าสุด จึงยังไม่มีไฟล์ภาพที่ใช้ได้ [หน้ารายการร้าน](https://ojamacard.com/category/683/pok%C3%A9mon-th/booster-pack/sword-shied/sword-shied-%E2%80%94-%E0%B8%AA%E0%B8%AD%E0%B8%87%E0%B8%A2%E0%B8%AD%E0%B8%94%E0%B8%99%E0%B8%B1%E0%B8%81%E0%B8%AA%E0%B8%B9%E0%B9%89-s5at) ระบุการ์ดนี้ แต่ยังไม่ได้ยืนยันไฟล์ภาพจากร้าน
