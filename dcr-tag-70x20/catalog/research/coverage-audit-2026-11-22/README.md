## วิธีอ่านสถานะ

- `present` = มีแถวข้อมูลในฐาน ไม่ได้ยืนยันว่าทุกช่องครบหรือข้อมูลถูกต้อง
- `indexed` = มีภาพและ SHA-256 ในดัชนี ไม่ได้รับประกันว่าภาพตรง variant หรือสภาพจริง
- `no local number match - candidate missing data` = ชุดอ้างอิงจับคู่กับชุดในฐานแบบอัตโนมัติได้ แต่ไม่พบเลขที่ตรง ต้องตรวจว่าเป็นการ์ดที่ขาดจริงหรือเป็นรหัสต่างรูปแบบ
- `set not mapped - review` = ยังจับคู่ชุดไม่ได้ อาจเป็นชุดที่ขาด ชุดย่อย โปรโม หรือชื่อเรียกอีกแบบ ห้ามนับว่าขาดแน่นอน
- `number match, name differs - review` = เลขตรงแต่ชื่อต่าง ต้องตรวจภาษา ชื่อแปล และข้อมูลการ์ดก่อน
- ลิงก์ `image` คือ URL ภาพที่ชุดข้อมูลอ้างอิงระบุ ไม่ใช่ผลยืนยันว่าทุกลิงก์ใช้งานได้หรือนำไปเผยแพร่ต่อได้

## ขอบเขตและข้อจำกัด

เทียบฐานการ์ดและดัชนีภาพในเครื่องกับ CardCorpus release 2026-11-21 โดยจับคู่ชุดจากชื่อเดียวกันหรือรหัสที่ไม่กำกวม แล้วเทียบเลขและชื่อการ์ด ยังไม่ได้ตรวจด้วยคนทุกใบ และไม่มีแหล่งใดรับประกันว่ารวมการ์ดทุกใบที่มีจริง ชุดโปรโม สินค้าแยก และ variant อาจถูกแบ่งต่างกันระหว่างแหล่ง

เลขการ์ดเก่าภาษาญี่ปุ่นบางชุดใช้รหัสอ้างอิงต่างกัน เช่น หมายเลข Pokédex เทียบกับลำดับในชุด จึงอาจขึ้นว่าไม่พบเลขแม้มีการ์ดเดียวกันอยู่แล้ว ข้อมูลที่ชื่อต่างหรือชุดยังจับคู่ไม่ได้ต้องตรวจเพิ่ม ไม่ควรนำจำนวนไปบวกเป็นยอดขาดจริง

เว็บไซต์ใช้ `public/data/card-catalog.json` ซึ่งมีอังกฤษ 23,913 ญี่ปุ่น 13,661 และไทย 2,995 รายการ มากกว่าฐานในเครื่อง 1 รายการสำหรับญี่ปุ่นและไทยจากข้อมูล curated ที่เพิ่มเฉพาะเว็บ รายงานนี้วัดฐานเครื่องและดัชนีภาพเป็นหลัก จึงยังไม่ถือว่าสองรายการพิเศษนั้นขาด

ข้อมูลต้นทางเต็มอยู่ใน `archive/source-packages/cardcorpus-dataset-2026-11-21.zip` โดยไฟล์ชุดอยู่ที่ `cardcorpus-dataset-2026-11-21/v1/sets/<reference-set-id>.json` ไฟล์ ZIP ผ่านการตรวจ SHA-256 แล้ว `9a32e343a18e43c293cbbff6a9a91f8e9c4784de5205e75fbbb86a64d900c95a`

## ตัวอย่างที่ตรวจแล้ว

- ไทย S5R 060 อิเอซซัน และ 061 พัดหมุนวน ไม่มีในฐานชุด S5R ที่ปัจจุบันมีเลข 001–059 แหล่ง CardCorpus ระบุข้อมูลและ URL ภาพทั้งคู่ และตัวอย่าง URL ตอบ HTTP 200; [เด็คลิสต์ทางการ](https://asia.pokemon-card.com/th/deck-build/recipe/GRDqyx-HYAYFg-IOqRlw/) ยืนยัน S5R 061/070 และ [รายการร้านไทย](https://ojamacard.com/category/691/pok%C3%A9mon-th/booster-pack?tskp=167) แสดงทั้ง 060 และ 061 ยังต้องตรวจภาพตรงรุ่นและสิทธิ์ใช้ก่อนนำเข้า
- ไทย S5a 012 มี data ในฐาน แต่ยังไม่มีภาพ [หน้าทางการ](https://asia.pokemon-card.com/th/card-search/detail/1190/) ตรงชื่อและเลข ทว่าลิงก์ภาพต้นทางส่งไฟล์ว่างในการทดลองก่อนหน้า ต้องหาแหล่งภาพไทยอื่น
- ทดลอง URL ภาพผู้สมัครรวม 6 ลิงก์ในสามภาษา ตอบ HTTP 200 แต่ยังไม่ได้ทดสอบ URL ภาพอื่นทุกรายการ
